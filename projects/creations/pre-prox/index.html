Prepare your data with PreproX: Smart Data Preparation

🌐 Welcome to PreproX!

In an effort to optimize my time during busy university days, I developed this web app as a time-saving solution for my machine learning projects. It streamlines the data preprocessing phase by providing an intuitive and user-friendly interface, allowing users to select the necessary transformations effortlessly. The final output is a clean, well-structured dataset, ready for machine learning models.

Our website, developed using Render, is accessible at https://preprox.onrender.com/. Upon visiting, you’ll be greeted with the following interface. The interface is designed for a smooth and intuitive user experience:

📂 Upload Your CSV File Users can upload a CSV file to process and transform their dataset. Simply drag and drop your file to get started!

📊 Data Visualization

Once uploaded, you can visualize your data with interactive graphs and tables to better understand your dataset before making modification

✅ Download Your Processed Dataset

After applying all necessary preprocessing steps, users can download the updated dataset in the ‘Get my new dataset’ section.

🚧 This project is still in development! 🚧

As the developer, I have big plans for PreproX! Future improvements include: 🔹 Rebuilding the frontend with React for better performance and interactivity. 🔹 Adding more advanced data cleaning and transformation techniques to enhance preprocessing capabilities.
